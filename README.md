# 8 Week SQL Challenge - Case Studies

## About this repository

The work here uses PostgreSQL-flavored SQL and follows the original case-study prompts. Queries are organized to make the analytical approach easy to review, reuse, and extend.

## Featured case studies

Danny's Diner is a customer and loyalty-program analysis for a Japanese restaurant. It answers twelve business questions, including customer spend, visit frequency, product preferences, member behavior, and loyalty-point calculations.

Balanced Tree Clothing Co. is a retail merchandising analysis for a clothing company. It answers sales, transaction, product-performance, basket-combination, and hierarchy-reconstruction questions for monthly reporting.

See the full walkthroughs, findings, and runnable SQL in [Danny's Diner](case-studies/01-dannys-diner/) and [Balanced Tree Clothing Co.](case-studies/02-balanced-tree-clothing/).
